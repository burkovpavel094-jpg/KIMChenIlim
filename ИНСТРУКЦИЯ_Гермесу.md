## 4. ЧТО ДЕЛАТЬ (ПОШАГОВО)

### Шаг 1: Забрать файл changes.csv

Способ A — через `curl`:
```bash
curl -s "https://raw.githubusercontent.com/burkovpavel094-jpg/KIMChenIlim/main/changes.csv" -o changes.csv
```

Способ B — через `gh api`:
```bash
gh api repos/burkovpavel094-jpg/KIMChenIlim/contents/changes.csv --jq '.content' | base64 -d > changes.csv
```

Способ C — через `wget`:
```bash
wget -q "https://raw.githubusercontent.com/burkovpavel094-jpg/KIMChenIlim/main/changes.csv" -O changes.csv
```

### Шаг 2: Найти необработанные строки

Ищи строки где в последней колонке написано `Нет`.

Пример на Python:
```python
import csv

with open('changes.csv', 'r', encoding='utf-8') as f:
    reader = csv.DictReader(f)
    for row in reader:
        if row['Обработано'] == 'Нет':
            print(f"НОВОЕ: {row['ФИО']} -> {row['Статус_стал']}")
            # Вносишь изменение в Персонал.xlsx
```

### Шаг 3: Внести изменения в Персонал.xlsx

Найди человека по ФИО и обнови статус в соответствующей колонке.

### Шаг 4: Отметить что обработано

После внесения изменений — обнови файл на GitHub, замени `Нет` на `Да`.

Как обновить через API (нужен токен Павла или твой):
```bash
# Получить текущий SHA файла
gh api repos/burkovpavel094-jpg/KIMChenIlim/contents/changes.csv --jq '.sha'

# Загрузить обновленный файл
gh api repos/burkovpavel094-jpg/KIMChenIlim/contents/changes.csv \
  --method PUT \
  -f message="Обработано: обновлены статусы" \
  -f content="$(base64 -w 0 changes.csv)" \
  -f sha="SHA_ИЗ_ПРЕДЫДУЩЕГО_ШАГА"
```
