# Инструкция для Гермеса (обновлено 24.06.2026)

## Что изменилось

Павел с Кими модернизировали систему. Теперь задачи имеют категории, и тебе нужно рассортировывать их по типам в Excel.

---

## Файлы (что осталось)

| Файл | Назначение | Действие |
|------|-----------|----------|
| `задачи.csv` | Задачи с категориями | **Читать и рассортировывать** |
| `собеседование.csv` | Кандидаты на работу | Обрабатывать как раньше |
| `changes.csv` | Архив | **Не трогать** |
| `планируемые_отпуска.csv` | Архив | **Не трогать** |

> **Важно:** changes.csv и планируемые_отпуска.csv больше не используются. Не обновляй их.

---

## Новая структура задачи.csv

```csv
Дата_внесения,Задача,Тип,Подтип,Обработано
```

| Колонка | Что означает | Возможные значения |
|---------|-------------|-------------------|
| `Дата_внесения` | Когда Павел добавил задачу | 2026-06-24 |
| `Задача` | Текст задачи | Любой текст |
| `Тип` | **Личное или Работа** | **Личное** / **Работа** |
| `Подтип` | Для рабочих задач | **Оперативная** / **На подумать** / **—** |
| `Обработано` | Статус обработки | **Нет** (новая) → ты ставишь **Да** |

> **Для "Личное"** колонка `Подтип` всегда **—** (прочерк).
> **Для "Работа"** колонка `Подтип` будет **Оперативная** или **На подумать**.

| Что Павел говорит | Тип | Подтип | Пример задачи |
|-------------------|-----|--------|---------------|
| "задача личная ..." | Личное | — | купить молоко |
| "задача работа оперативная ..." | Работа | Оперативная | сломался пресс |
| "задача работа на подумать ..." | Работа | На подумать | пересмотреть график |
| "задача ..." (без уточнения) | Работа | Оперативная | позвонить Владу |

## Что тебе делать

### Шаг 1: Забрать файл
Как обычно — скачай `задачи.csv` с GitHub.

### Шаг 2: Рассортировать по таблицам

Теперь задачи нужно разделить на **3 группы** в Excel:

```
┌─────────────────────────────────────────────────────────┐
│  ТАБЛИЦА 1: ЛИЧНЫЕ ЗАДАЧИ                              │
│  (Тип = "Личное")                                       │
│  Колонки: Дата | Задача | Обработано                    │
├─────────────────────────────────────────────────────────┤
│  ТАБЛИЦА 2: РАБОТА — ОПЕРАТИВНЫЕ                       │
│  (Тип = "Работа", Подтип = "Оперативная")               │
│  Колонки: Дата | Задача | Обработано                    │
├─────────────────────────────────────────────────────────┤
│  ТАБЛИЦА 3: РАБОТА — НА ПОДУМАТЬ                       │
│  (Тип = "Работа", Подтип = "На подумать")                │
│  Колонки: Дата | Задача | Обработано                    │
└─────────────────────────────────────────────────────────┘
```

### Шаг 3: Поставить "Да"
После обработки задачи в исходном `задачи.csv` поставь **"Да"** в колонку `Обработано`.

Кими при следующей выгрузке автоматически удалит эти строки.

### Шаг 4: Залить обратно
Загрузи обновлённый `задачи.csv` на GitHub (как раньше).

## Пример данных

```csv
Дата_внесения,Задача,Тип,Подтип,Обработано
2026-06-24,купить молоко,Личное,—,Нет
2026-06-24,сломался пресс на линии 3,Работа,Оперативная,Нет
2026-06-24,пересмотреть график отпусков на июль,Работа,На подумать,Нет
2026-06-24,позвонить Владу,Работа,Оперативная,Нет
2026-06-24,забрать машину из ремонта,Личное,—,Нет
```

Как рассортировать:

| Таблица | Какие строки попадают |
|---------|----------------------|
| Личные | купить молоко, забрать машину |
| Работа Оперативные | сломался пресс, позвонить Владу |
| Работа На подумать | пересмотреть график |
