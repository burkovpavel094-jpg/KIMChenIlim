# KIMChenIlim — Автоматизация задач и собеседований

## Как работаем

### Принцип: "Накопление + выгрузка по команде"

Для экономии токенов:
1. Павел пишет информацию в чат — Кими запоминает в накопитель
2. Команда **"выгружай"** — Кими разом всё на GitHub
3. Команда **"покажи что накоплено"** — показать без выгрузки

## Файлы в репозитории

| Файл | Назначение | Статус |
|------|-----------|--------|
| `задачи.csv` | Задачи (с категориями) | ✅ Активный |
| `собеседование.csv` | Кандидаты на работу | ✅ Активный |
| `changes.csv` | Архив (персонал) | ❌ Не используется |
| `планируемые_отпуска.csv` | Архив (отпуска) | ❌ Не используется |

## Структура задачи.csv

```
Дата_внесения,Задача,Тип,Подтип,Обработано
```

| Колонка | Описание | Варианты |
|---------|----------|----------|
| `Дата_внесения` | Когда добавлено | 2026-06-24 |
| `Задача` | Текст задачи | Произвольный |
| `Тип` | Личное или Работа | Личное / Работа |
| `Подтип` | Для "Работа" | Оперативная / На подумать |
| `Обработано` | Статус у Гермеса | Да / Нет |

> **Для "Личное"** колонка `Подтип` остаётся пустой (прочерк).

## Как писать задачи

| Что говорите | Тип | Подтип | Пример |
|-------------|-----|--------|--------|
| `задача личная ...` | Личное | — | "задача личная купить молоко" |
| `задача работа оперативная ...` | Работа | Оперативная | "задача работа оперативная сломался пресс" |
| `задача работа на подумать ...` | Работа | На подумать | "задача работа на подумать пересмотреть график" |
| `задача ...` (без уточнения) | Работа | Оперативная | "задача позвонить Владу" |

## Автоматическая чистка

При каждой выгрузке Кими удаляет из `задачи.csv` строки со статусом **"Да"** (обработанные Гермесом).

## Участники

| Участник | Роль |
|----------|------|
| **Павел** | Начальник, даёт информацию в чат |
| **Кими** | Запоминает, выгружает на GitHub, чистит обработанное |
| **Гермес** | Агент на ПК Павла. Забирает файлы, рассортировывает задачи по типам в Excel |
