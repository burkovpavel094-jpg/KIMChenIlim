# KIMChenIlim — Автоматизация персонала и задач

## Как работаем сейчас (с 16.06.2026)

### Основной принцип: накопление + выгрузка

Для экономии токенов мы работаем по схеме **"накопление + выгрузка по команде"**:

1. **Вы пишете информацию** в чат (персонал, задачи, скрины отпусков)
2. **Кими запоминает** — данные накапливаются в памяти
3. **Команда "выгружай"** — Кими разом выгружает всё на GitHub (1-3 загрузки вместо 10-30)

⚠️ **Важно:** накопитель живёт только в текущей сессии. Выгружайте регулярно (не реже раза в 2-3 часа)!

## Как писать информацию

### Персонал → changes.csv

Пишете текстом, Кими понимает контекст:
- "Цыпина на больничный"
- "Шубин в отпуск с 15 июля"
- "Гришко О.Н. болеет"

Формат ФИО: **Фамилия И.О.** (инициалы, не полное имя)

### Задачи → задачи.csv

Начинайте со слова **"задача"**:
- "Задача: позвонить клиенту"
- "задача купить краску до пятницы"

### Отпуска → планируемые_отпуска.csv

Присылайте **скриншоты** заявлений. Кими извлекает:
- ФИО
- Даты начала и окончания
- Вид отпуска
- Количество дней
