# KIMChenIlim — Автоматизация персонала, задач и собеседований

## Как работаем

### Принцип: "Накопление + выгрузка по команде"

Для экономии токенов:
1. Павел пишет информацию в чат — Кими запоминает в накопитель (`buffer`)
2. Команда **"выгружай"** — Кими разом всё на GitHub
3. Команда **"покажи что накоплено"** — показать без выгрузки

## Автоматическая чистка обработанных записей

При КАЖДОЙ выгрузке Кими автоматически удаляет из файлов строки со статусом **"Да"** (обработанные Гермесом):

| Файл | Чистка "Да" | Когда чистится |
|------|-------------|----------------|
| `changes.csv` | ✅ Да | При каждой выгрузке |
| `задачи.csv` | ✅ Да | При каждой выгрузке |
| `планируемые_отпуска.csv` | ❌ Нет | Без чистки |
| `собеседование.csv` | ❌ Нет | Без чистки |

> **Важно:** Гермес после обработки Excel ставит "Да" в колонку `Обработано`. Кими видит это и удаляет строки при следующей выгрузке.

## Файлы в репозитории

| Файл | Назначение | Как пишете |
|------|-----------|-----------|
| `changes.csv` | Персонал (больничные, отпуска) | Текст: "Цыпина на больничный" |
| `задачи.csv` | Задачи | Начните со слова "задача" |
| `планируемые_отпуска.csv` | Отпуска со скринов | Пришлите скрин заявления |
| `собеседование.csv` | Кандидаты на работу | Начните со слова "собеседование" |
