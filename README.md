## 🔄 Как работает процесс

### Персонал (changes.csv)

**Когда использовать:** Павел пишет текстом о статусе сотрудника

**Примеры:**
- "Цыпина на больничный"
- "Шубин в отпуск с 15 июня"
- "Гришко О.Н. болеет"

**Что делает Кими:**
1. Разбирает сообщение
2. Добавляет строку в `changes.csv`
3. ФИО в формате: `Фамилия И.О.` (инициалы, не полное имя!)
4. После обработки Гермесом — удаляет строки со статусом "Да"

**Формат файла:**
```csv
Дата_внесения,ФИО,Статус_был,Статус_стал,Дата_начала,Дата_окончания,Комментарий,Обработано
2026-06-15,Гришко О.Н.,работает,больничный,2026-06-15,,,Нет
```

---

### Планируемые отпуска (планируемые_отпуска.csv)

**Когда использовать:** Павел присылает скриншот заявления на отпуск

**Что извлекает Кими:**
- ФИО
- Дата начала и окончания
- Вид отпуска
- Количество дней

**Формат файла:**
```csv
Дата_внесения,ФИО,Дата_начала,Дата_окончания,Вид,Комментарий
2026-06-16,Вестеров С.Ю.,2026-07-05,2026-07-22,Основной отпуск,18 дней
```

---

### Задачи (задачи.csv)

**Когда использовать:** Павел пишет со словом "задача"

**Примеры:**
- "Задача: позвонить клиенту"
- "задача купить краску до пятницы"

**Формат файла:**
```csv
Дата_внесения,Задача,Статус,Обработано
2026-06-16,позвонить клиенту,Новая,Нет
```

---

## 🗑️ Правила очистки

- `changes.csv` — Кими удаляет строки со статусом "Да" после обработки
- `задачи.csv` — Гермес удаляет или оставляет по своему усмотрению
- `планируемые_отпуска.csv` — НЕ удаляется, хранится как архив
